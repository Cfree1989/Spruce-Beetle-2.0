# Submissions

Save the confirmation email for every Graduate School submission. LSU tells students to keep these. A PDF export of the email is enough. Name files with the date you submitted.

- Application for Degree confirmation
- Request for Final Defense confirmation
- Degree audit and Program of Study
- Transfer-credit paperwork, if any
- Committee approval and defense documents
- Formatting checklist and editor messages
- LSU Scholarly Repository upload confirmation
- Editor correction requests and the final approval message

Forms: [LSU Graduate Student Forms](https://www.lsu.edu/graduateschool/students/grad_student_forms.php). Defense requests can also go to gradsvcs@lsu.edu.
