# Thesis planning

Working folder for the Spring 2027 master’s thesis: dates, the project proposal, and the confirmation emails the Graduate School tells you to keep.

Checked against LSU’s published calendars on October 26, 2026. Department deadlines can be earlier than the Graduate School dates. When they are, the department date is the one that counts.

| Path | What goes here |
| --- | --- |
| [Calendar.md](Calendar.md) | Deadlines, LSU A&M employee holidays, and student breaks from now through commencement. |
| [Spring-2027-Thesis.ics](Spring-2027-Thesis.ics) | Employee holidays and thesis deadlines only, for Outlook. File → Open & Export → Import/Export → Import an iCalendar (.ics). |
| [Proposal/](Proposal/) | Project proposal and any other planning drafts. |
| [Submissions/](Submissions/) | Confirmation emails and copies of forms after you submit them. |

This folder is inside the Spruce Beetle repo. Anything you drop here is part of the working tree and will be included if you commit.
